# ICS Fire Systems

A Next.js 16 equipment catalog with Arabic PDF quotations generated by the Node.js route POST /api/quote.

## Local development

Use Node.js 24 and run npm ci, then npm run dev. Open http://localhost:3000.

## Deploy to Vercel

1. [Import this GitHub repository in Vercel](https://vercel.com/new) and grant the GitHub integration access to Abdoakram512/ics-fire.
2. Select the **Next.js** preset, repository root, **Node.js 24.x**, and **main** as the production branch. Keep the default build and output settings. No environment variables are required.
3. Deploy and use the Vercel URL for the site. Vercel can build previews for future pull requests and deploy updates to main.

The GitHub Pages URL currently publishes the repository README. Pages serves static files and cannot run the POST route used for PDF generation. Once you verify the Vercel deployment, update links pointing to the Pages URL.

## Verify a deployment

Run the following against the public Vercel URL. It checks pages, a public asset, a valid PDF download, and the API response for an invalid quantity.

    node scripts/check-deployment.mjs https://YOUR-PROJECT.vercel.app

To run the same check locally, run npm run build and npm run start, then run node scripts/check-deployment.mjs in another terminal. GitHub Actions runs this check against the production build on pull requests and pushes to main.
